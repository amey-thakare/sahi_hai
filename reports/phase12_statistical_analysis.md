# Phase 12 — Statistical Analysis
## McNemar's Test
- Null Hypothesis: Marginal probabilities for correct classification are equal for Old ICP and New Canonical ICP (alpha=0.05).
- b (New correct, Old wrong): 141
- c (Old correct, New wrong): 410
- McNemar chi2: 130.3521
- p-value: 0.0000e+00
- Conclusion: The difference in performance is statistically significant.
