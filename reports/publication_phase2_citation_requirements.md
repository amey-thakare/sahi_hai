# Publication Phase 2 Citation Requirements

The following claims in the paper require authoritative citation support. No citations have been fabricated.

| Citation ID | Claim Requiring Citation | Recommended Literature Topic | Why Citation is Needed |
| :--- | :--- | :--- | :--- |
| 1 | "Historical approaches rely on extracting structural and lexical features from the URL string..." | Lexical and Structural URL Detection | Need foundational papers establishing early heuristic/structural URL analysis. |
| 2 | "Extensive literature supports the use of Random Forests, Support Vector Machines, and Gradient Boosting to classify URLs..." | Machine Learning for Malicious URL Detection | Need papers demonstrating the shift from heuristics to classical ML using engineered features. |
| 3 | "Recent advances leverage deep learning, particularly Convolutional Neural Networks (CNNs), Long Short-Term Memory (LSTMs), and Transformer models..." | Deep Learning and Transformer-Based URL Detection | Need papers showing the application of deep sequence models to URL character/sub-word tokens. |
| 4 | "Selective classification allows models to abstain from prediction on uncertain inputs. Early exit architectures apply this dynamically..." | Selective Classification and Early Exit Systems | Need papers defining selective classification theory and early-exit neural architectures. |
| 5 | "Conformal prediction is a framework that yields valid, finite-sample prediction sets with user-defined marginal coverage guarantees..." | Conformal Prediction for Reliable ML | Need foundational conformal prediction literature (e.g., Vovk, Shafer, or recent tutorials like Angelopoulos & Bates). |
| 6 | "Feature-wise Linear Modulation (FiLM) provides a mechanism to condition neural network representations based on auxiliary input..." | Feature Fusion and FiLM-Based Conditioning | Need the original FiLM paper (Perez et al., 2018) or similar foundational multi-modal fusion work. |
